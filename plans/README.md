# Plans and Task Tracking

This directory contains planning documents and task lists for Muesli development.

## Files

- **TODO.md** - Active task list for current development work
  - When agents are asked to "add a todo" or "note this for later", items go here
  - Organized by category (Current Work, High Priority, Features, etc.)
  - Completed items are archived at the bottom

## Purpose

Separate planning documents from the main codebase to:
- Keep the repository root focused on code and documentation
- Provide a dedicated space for work-in-progress tracking
- Make it easy to find and update task lists

## Note for Agents

Per **AGENTS.md Working Rules #6**:
> When asked to "add a todo" or "note this for later", add it to `plans/TODO.md` and continue working without interruption.

Always reference `plans/TODO.md` (not just `TODO.md` in the root).
