# DMG Background Image Generator Prompt

Use this prompt with an image generator (DALL-E, Midjourney, Stable Diffusion, etc.) to create the DMG background.

## Image Specifications
- **Dimensions**: 1280x720 pixels
- **Format**: PNG
- **Aspect Ratio**: 16:9 (landscape)

## Prompt

```
Create a beautiful, clean macOS-style installation background image. 

Background: Warm, inviting gradient from cream (#FFF8F0) transitioning diagonally from top-left to bottom-right, with subtle orange-to-gold tones (#E86A34 to #F9C66B) at very low opacity (10-15%) creating depth. The overall feel should be warm, granola-inspired, and premium.

Style: Clean, minimal, modern macOS aesthetic. NO app icons, NO folder icons, NO arrows, NO text - just a beautiful gradient background. The design should feel warm, inviting, and professional.

Color Palette:
- Base: #FFF8F0 (cream)
- Gradient accent: #E86A34 to #F9C66B (orange to gold)
```

## Notes

- **Do NOT include** app icons, folder icons, arrows, or text - these are all automatically handled by the DMG creation script
- Just create a beautiful gradient background
- The overall design should feel warm and inviting, matching a "granola-inspired" aesthetic
- Keep it minimal and clean - less is more

## Layout Reference

The DMG window is 800x400 pixels, and this 1280x720 background will be scaled to fit. The app icon and Applications folder icon are automatically placed by the DMG script, so your background just needs to be a beautiful gradient.
